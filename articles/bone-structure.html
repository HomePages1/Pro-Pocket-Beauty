FASHION GUIDE

骨格診断
初心者ガイド

自分に合うシルエットを知って、
服選びをもっと簡単に。

INTRODUCTION

骨格診断って
何？

骨格診断は、体の立体感やラインなどを参考にして、 似合いやすい服のシルエットや素材を考える方法です。

「服を着ると着太りして見える」 「なぜかしっくりこない」 そんなときの服選びのヒントになります。

ルールではありません

骨格タイプは、 「この服は絶対NG」という決まりではありません。 自分の好みと組み合わせて使うのがおすすめです。

01 / BASIC

基本は
3タイプ

一般的な骨格診断では、 大きく3つのタイプに分けて考えます。

STRAIGHT

ストレート

立体感があり、シンプルで すっきりしたスタイルが映えやすいタイプ。

WAVE

ウェーブ

やわらかなラインを活かした 軽やかなスタイルが得意とされるタイプ。

NATURAL

ナチュラル

フレーム感を活かした ラフでゆったりしたスタイルが得意とされるタイプ。

02 / STRAIGHT

骨格ストレート

体に立体感があり、 シンプルで上品なスタイルが なじみやすいとされるタイプです。

スタイルのイメージ

シンプル・きれいめ・ジャストサイズ。 すっきりしたシルエットを意識すると コーディネートしやすくなります。

✓

ジャストサイズを試す

✓

シンプルなデザインを選ぶ

✓

縦のラインを意識する

03 / WAVE

骨格ウェーブ

やわらかなラインを活かした 軽やかなファッションが なじみやすいとされるタイプです。

スタイルのイメージ

コンパクト・やわらかい素材・ ウエストを意識したシルエットなど。

✓

軽やかな素材を試す

✓

コンパクトなサイズ感を試す

✓

ウエストラインを意識する

04 / NATURAL

骨格ナチュラル

フレーム感を活かした ラフでゆったりしたスタイルが なじみやすいとされるタイプです。

スタイルのイメージ

オーバーサイズ・レイヤード・ ナチュラル素材などを取り入れる方法があります。

✓

ゆったりしたシルエットを試す

✓

レイヤードを楽しむ

✓

ラフな素材を取り入れる

05 / CHECK

自分の骨格タイプを
知るには？

自己診断では、 体の一部分だけで判断しないことがポイントです。

✓

肩や鎖骨まわりを見る

✓

上半身・下半身の立体感を見る

✓

関節や骨の存在感を見る

✓

実際に服を着てシルエットを確認する

迷ったら？

自己診断だけで無理に決めず、 複数の服を実際に着て比較してみましょう。

06 / TOPS

トップス選びは
シルエットから

トップスは顔や上半身に近いため、 全体の印象を大きく左右します。

01

ストレート

すっきりしたジャストサイズを試す。

02

ウェーブ

コンパクトで軽やかなデザインを試す。

03

ナチュラル

ゆったりしたシルエットも試してみる。

07 / MATERIAL

素材でも
印象が変わる

同じデザインでも、 生地の厚みやハリ、柔らかさによって 見え方は変わります。

試着するときのポイント

正面だけでなく、 横から見たシルエットも確認しましょう。

「着たときに自然に見えるか」を 基準にすることが大切です。

08 / BOTTOMS

ボトムスは
全身のバランスを見る

パンツやスカートは、 トップスとの組み合わせで 全体のバランスが変わります。

✓

ウエスト位置を確認する

✓

丈の長さを確認する

✓

靴まで合わせて見る

DON'T

骨格診断で
やりすぎないこと

×

診断結果だけで服を全部決める

×

好きな服をすべて諦める

×

他人の骨格タイプと比較しすぎる

×

体型そのものを良し悪しで考える

10 / SHOPPING

買い物で
失敗しにくくする

01

サイズを確認

S・M・Lだけでなく実寸も確認。

02

全身を見る

トップスだけで判断しない。

03

手持ち服と合わせる

今持っている服との相性も確認。

PERSONAL STYLE

「似合う」と
「好き」を両立する

骨格診断は、 おしゃれを制限するためのものではありません。

好きな服をベースにして、 サイズ・丈・素材・組み合わせを調整するだけでも 自分らしいスタイルを作れます。

迷ったらシルエットから

色やブランドより先に、 「全身の形が自然に見えるか」を確認してみましょう。

BEGINNER STEP

初心者は
この順番でOK

01

3タイプを知る

ストレート・ウェーブ・ナチュラルの違いを確認。

02

自分を観察する

肩・鎖骨・関節・体の立体感などを見る。

03

実際に服を着る

シルエットの違いを比較する。

04

好きな服に応用する

自分らしいファッションに取り入れる。

SUMMARY

骨格を知ると、
服選びがもっと楽になる。

骨格診断は、 自分の体の特徴を知り、 似合いやすいシルエットを探すためのヒントです。

ストレート・ウェーブ・ナチュラルの どれかに無理に当てはめる必要はありません。 実際に着てみて、自分が心地よく感じる服を選びましょう。
