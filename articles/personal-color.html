BEAUTY GUIDE

パーソナルカラー
初心者ガイド

似合う色を知って、
もっと自分らしく。

INTRODUCTION

パーソナルカラーって
何？

パーソナルカラーとは、 自分の肌や髪、瞳などの印象と調和しやすい色を 考えるための方法です。

「この服を着ると顔色が明るく見える」 「このリップは自然になじむ」 という色選びのヒントになります。

大切なポイント

パーソナルカラーは 「この色を絶対に使ってはいけない」 というルールではありません。

01 / BASIC

基本は
4つのタイプ

一般的な分類では、 春・夏・秋・冬の4つのタイプに分けて考えます。

SPRING

イエベ春

明るく軽やかな色が得意とされるタイプ。

SUMMER

ブルベ夏

やわらかく涼しげな色が得意とされるタイプ。

AUTUMN

イエベ秋

深みのある落ち着いた色が得意とされるタイプ。

WINTER

ブルベ冬

はっきりしたコントラストのある色が得意とされるタイプ。

02 / UNDERTONE

イエベとブルベの
基本

パーソナルカラーでは、 大きく「イエローベース」と 「ブルーベース」という考え方があります。

YELLOW BASE

イエベ

黄みを含んだ色との調和を考えるグループ。

BLUE BASE

ブルベ

青みを含んだ色との調和を考えるグループ。

ただし、肌の色だけで自己判断するのは難しいため、 目安として考えるのがおすすめです。

03 / CHECK

自分のタイプを
考えるヒント

自分でチェックするときは、 一つの項目だけで決めないことがポイントです。

✓

白・アイボリーなどの服を比べてみる

✓

ゴールド・シルバー系のアクセサリーを比べる

✓

リップやチークの色を比較する

✓

顔色が明るく見える色を確認する

明るく見える？

「肌がきれいに見えるか」 「顔色が自然に見えるか」を基準にすると 比較しやすくなります。

04 / SPRING

イエベ春

明るく、軽やかな印象の色が 得意とされるタイプです。

色選びのイメージ

コーラル、ピーチ、明るいベージュ、 明るめのグリーンなど。

メイクでは、 明るくフレッシュな印象のカラーを 取り入れる方法があります。

05 / SUMMER

ブルベ夏

やわらかく涼しげな印象の色が 得意とされるタイプです。

色選びのイメージ

ローズ、ラベンダー、ソフトピンク、 淡いブルーなど。

淡く落ち着いた色を使うと、 やわらかな雰囲気を作りやすくなります。

06 / AUTUMN

イエベ秋

深みのある落ち着いた色が 得意とされるタイプです。

色選びのイメージ

テラコッタ、ブラウン、カーキ、 マスタードなど。

深みのあるカラーを取り入れると、 大人っぽい印象を作りやすくなります。

07 / WINTER

ブルベ冬

はっきりした色や コントラストのある色が 得意とされるタイプです。

色選びのイメージ

ロイヤルブルー、ワイン、 フューシャピンク、ブラックなど。

メリハリのある色を取り入れると、 印象的なスタイルを作りやすくなります。

08 / MAKEUP

メイクに
取り入れてみよう

パーソナルカラーは、 アイシャドウ、チーク、リップなどの 色選びに活用できます。

01

リップ

顔の印象を変えやすいので、 まず試しやすいアイテムです。

02

チーク

肌になじむ色を選ぶと自然に仕上げやすくなります。

03

アイシャドウ

普段使う色から少しずつ試してみましょう。

09 / FASHION

服の色にも
活用できる

パーソナルカラーを知っておくと、 洋服を選ぶときにも参考になります。

迷ったら顔まわりから

トップス、ストール、アクセサリーなど、 顔の近くにくるアイテムから色を試してみましょう。

ボトムスやバッグなど、 顔から離れたアイテムなら 好きな色を自由に取り入れるのもおすすめです。

10 / SHOPPING

買い物で
失敗しにくくする方法

✓

顔の近くで色を確認する

✓

自然光でも確認する

✓

手持ちの服と合わせて考える

✓

「診断結果」だけで購入を決めない

CHECK

パーソナルカラーで
よくある勘違い

×

似合わない色は絶対に使えない

×

肌の色だけでタイプが決まる

×

診断結果と違う色は全部NG

好きな色も大切

パーソナルカラーは、 おしゃれを楽しむためのヒントとして 使うのがおすすめです。

BEGINNER STEP

初心者は
この順番でOK

01

自分の得意な色を探す

まずは鏡の前で色を比較。

02

リップで試す

顔色の変化を確認しやすいアイテムです。

03

服に取り入れる

トップスなど顔に近いアイテムから試します。

04

好きな色と組み合わせる

「似合う」と「好き」を両方楽しみましょう。

SUMMARY

似合う色を知ると、
選ぶのがもっと楽しくなる。

パーソナルカラーは、 自分に似合う色を探すための便利なヒントです。

イエベ・ブルベだけに縛られず、 実際に顔色や全体の印象を見ながら 自分に合う色を見つけていきましょう。
